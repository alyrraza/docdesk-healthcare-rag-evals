## Amendments to the FINAL rule

- First amendment (2026-10-15, before any FINAL run): superseded for the final choice by the second. The one item rule would have turned hybrid noise into a kept technique, so the candidates became FINAL_SIMPLE (cap 4 alone) and FINAL_FULL (cap 4 plus hybrid, plus top_k 8 if it passed), with FINAL_FULL frozen only if it beat FINAL_SIMPLE by 2 items.
- Second amendment (2026-10-15, before any FINAL_FULL run and any test run): FINAL_FULL and top_k 8 were not completed because the daily generator token budget was spent (168122 of 170000). FINAL is FINAL_SIMPLE, E5 cap 4 alone, the only technique whose paired interval excludes zero on dev.

## Limitations

- n is 30 answerable dev items, so every interval is wide and an effect below about 0.15 cannot be told from noise. Choosing the best of several configs on the same 30 items overfits, which is why every config tried is listed above.
- The judge labels are Claude drafts with Ali review pending, so no human has validated the judges yet, and kappa rests on 24 independent items.
- The policy filter gaps (dose and diagnosis cases) remain open and are not part of these runs.
- The injection items (gi-078, gi-079) are not run: they need the fixture loader (T122).
- E5 cap 4 was seen before the pre-registration, because its run was made earlier for judge calibration, so it is not a blind result.
- Hybrid retrieval showed no clear difference, and top_k 8 was not completed because the daily generator token budget was spent.
- Chunk size and strategy techniques were not tried: a re-ingest changes chunk ids and invalidates the stored runs (review finding F8), and a reranker needs a model download outside the dependency list.
